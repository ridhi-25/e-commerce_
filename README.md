# E-commerce Node.js + React

Quick scaffold for a Node.js (Express) + MongoDB backend and React (Vite) frontend.

Setup

1. Install server deps:

```bash
cd server
npm install
```

2. Install client deps:

```bash
cd client
npm install
```

3. Run backend (with nodemon recommended):

```bash
cd server
npm run dev
```

4. Run client:

```bash
cd client
npm run dev
```
